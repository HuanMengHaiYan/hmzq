# GLB 评估 · Tripo v3.1（`tripo_convert_0f1667cc….glb`）

检查时间 2026-11-13 · 文件 5.06 MB · 工具 `test/glb-check.py`

## 一句话结论

**是目前几版里最好的一版**：面数游戏友好、有 UV 有法线、库边高度几乎精确、六条腿齐全、台呢是一整块干净平面。
但要当游戏资产用，有 4 处必须改：**台面偏方 9~14%**、**台呢下面叠了 3 层板**、**袋口几何杂乱**、**金属没有金属感**。

## 袋口实测（向下射线穿透，`0 层 = 真通孔`）

台面下方不是空的，叠了**三层水平板**：

| 高度 | 是什么 |
|---|---|
| 755 mm | 台呢面 |
| 659 mm | 库边下方的一层板 |
| 493 mm | 台呢正下方的一层板（几乎整张台面大小） |

**角袋**（沿 45° 对角线从角点向内扫）：

```
距角点  0~ 28 mm  →  0 层（空）
距角点 37~ 65 mm  →  2~4 层   <-- 就是截图里那个"环/耳朵"
距角点 74~129 mm  →  0 层（空）
距角点 138 mm 起  →  2 层（台呢 + 下板）
```

孔本身是通的，但**开口中段横着一圈 4 层重叠的几何**，从上看是环、从侧面看是拱。这就是你截图里那只「挂在角上的耳朵」，它不是挡孔，是悬在孔中间。

**中袋**（沿长边法线从外沿向内扫）：

```
-751 ~ -692 mm  →  2 层（外框，完整未切断）
-680 ~ -645 mm  →  0 层（通口，只有 35 mm 宽）
-633 ~ -573 mm  →  2 → 8 层（袋内塞满重叠面）
-562 mm 以内    →  1 层（台呢）
```

中袋通口只有 **35 mm**（真实 95 mm），而且口内 8 层重叠面。截图里看到的「碗」就是这堆面。

## 材质与贴图

```json
{"doubleSided": true,
 "normalTexture": {"index": 0},
 "pbrMetallicRoughness": {"baseColorTexture": {"index": 1},
                          "metallicFactor": 0, "roughnessFactor": 0.5}}
```

- **metallicFactor = 0**：六条银色腿渲染出来是「米白塑料」，因为在 glTF 里 metallic=0 就没有金属反射，全靠 baseColor 硬画。这是 Tripo 通病。
- 没有 metallic-roughness 贴图、没有 AO → 无法后期把腿拆出来单独调金属度（只能改几何/分材质）。
- baseColor 里**台呢被切成两块 UV 岛，一深一浅**（亮绿 #3CD 与暗绿各一块）→ 台呢上会有可见色差接缝。
- 木框 baseColor 带**雕花纹理**（菱形、卷草），法线贴图也有对应凹凸 —— 正是这轮提示词想删掉的东西。
- UV 岛之间 padding 不足，绿/白渗到相邻岛边缘。
- **doubleSided = true**：渲染成本翻倍，且法线朝内时会出现黑面，游戏里应关掉。

## 结构质量

**1133 个连通分量** —— 模型不是焊接的实体，而是上千个面片拼起来的。后果：

- Blender 里做布尔挖洞会很难（布尔要求相对干净的开放/闭合曲面）。
- 好消息是**部件天然分离**：台呢（299 顶点）、两条长库边顶面、裙板、下板（555 顶点）、腿都能单独选中删除或替换。
- 空腔/穿模风险高：从袋口看进去能看到层层叠叠的面。

## 改造清单（按性价比排序）

1. **重正比例**（必做，5 分钟）
   台呢拉伸到 2540 × 1270：Z 轴 ×1.029、X 轴 ×0.886。或用 `Layout` 工具直接按台呢四角对齐到 2:1。
2. **删掉台呢下面的板**（必做）
   台呢下方 y≈493 mm 那块平板是袋口「不通」的直接原因之一，删掉后中袋/角袋往下就通了。保留 659 mm 那层（库边结构支撑）。
3. **清袋口杂物**（必做）
   - 角袋：删掉距角点 37~65 mm 那一圈 4 层重叠面（就是那个环）。
   - 中袋：删掉口内 2~8 层重叠面，缺口按 95 mm 重开。
   - 六处开口统一做成「台呢边缘齐平、孔壁垂直、直通桌下」。
4. **分材质**（强烈建议）
   现在单材质 metal=0，银腿救不回来。按 UV 岛把台呢 / 木框 / 金属腿分成 3 个材质槽，金属那槽 metallic≈0.9、roughness≈0.35。
5. **关 doubleSided**，重新计算法线朝外。
6. 可选：把 4096² 贴图降到 2048²（5 MB → 约 2 MB），台呢两块 UV 岛合并成一块平色。

## 关于「120 万面」

这个 GLB 是 **1.84 万面**，不是 120 万。两种可能：Tripo 导出时选了默认减面，或者下载的是「标准精度」而非「超清」。1.84 万面对面数来说反而是好事（游戏里够用，120 万面根本进不去），但如果是要拿去做高精度底模，得在 Tripo 里重新导出高精度版本。
