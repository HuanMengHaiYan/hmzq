| 面板 | 文件 |

`preview-2x2.png` 是四张的拼版预览，不用上传。
`src-front-raw.png` / `src-left-raw.png` 是两张原始生成图（1024×1024 未对齐版），留作以后重新对齐用。

## 技术规格（四张完全一致）

| 项 | 值 |
|---|---|
| 尺寸 | 1024 × 1024 PNG，RGB，纯白 `#FFFFFF` 背景，无地面、无投影、无水印 |
| 比例尺 | **0.3121 px/mm**：长边 2820 mm = 880 px，短边 1550 mm = 484 px |
| 基线 | 脚底统一在 y = 666，物体水平居中 |
| 相机 | 正交（平行投影），俯角 8~10°，只露出窄条绿色台面 |
| 镜像关系 | `back` = `front` 水平镜像；`right` = `left` 水平镜像 —— 台球桌关于长轴、短轴都对称，这样四张的腿型与饰条 100% 一致，比让 AI 画四次可靠 |
| 文件大小 | 125 KB ~ 300 KB，远低于 Tripo 的 20 MB 上限 |

## 结构约定（模型只负责这些）

- **6 条腿**：4 角 + 2 长边中点，倒收分六角棱柱、大块钻石斜切面、顶端方套箍、底部短圆柱脚圈，**全香槟银阳极氧化铝**，无木质段
- **顶框**：深浓缩胡桃木，内沿一道香槟银细饰条，顶面小菱形瞄准点
- **裙板**：同色深胡桃木，上下两道宽幅哑光银铝饰条，转角斜切银块
- **台面**：**一整块封闭平板，无袋口、无开孔、无凸起** —— 6 个袋口后续由程序化 / Blender 布尔挖洞，不进 AI 模型
- **桌下**：完全敞开，无搁板 / 底板 / 横梁 / 网兜 / 任何悬挂物

配色：台呢 `#1C6B4A`、木 `#4A2A1B`、银 `#C9BFA8`、橡胶近黑。

## 已知与理想状态的差异（Tripo 会折中）

1. 左 / 右视的腿部金属环比前视多 1~2 道，斜切面也更碎；前视更接近目标的"大块钻石切面"。
2. 左 / 右视俯角略小于前视（绿色台面可见约 10% vs 前视 18%）。
3. 台面四角与长边中点有**黑色小块**（袋口位置提示）。它们是平的、嵌在框内，不是凸起也不是悬挂物；若生成结果带浅凹，程序化台面会覆盖掉。

## 生成后必查（上一轮四个模型全栽在这）

| 检查 | 合格线 | 上一轮实测 |
|---|---|---|
| 有贴图 | GLTF `images ≥ 1`、材质含 `baseColorTexture` | **1 个空材质、0 贴图** |
| 有 UV | 顶点属性含 `TEXCOORD_0` | **缺失** |
| 真开孔 | 本轮**不要求**（袋口由程序化挖） | — |
| 长宽比 | ≈ 1.82（外廓 2820 / 1550） | 1.44 / 1.72 / 1.58 / 1.51 |
| 高长比 | ≈ 0.32 | 0.38 ~ 0.49（偏高偏方） |
| 腿数 / 桌下 | 6 条 / 完全敞开 | 4 条车削柱 / 有搁板横梁 |

面板建议：模型版本 v3.1 / P1.0 / 当前 F2.0 均可，Face Limit 高（5~8 万），Quad Mesh 开，Symmetry 关，**Texture + PBR 必须确认真的勾上**，Style 选 None，负向词用 `docs/Tripo-台球桌模型提示词-v2.md` 第〇节的完整档。
